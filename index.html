AWS / IAC

Multi-Region Kubernetes via Terraform

Architecture Summary

This project leverages Terraform to build an active-passive multi-region Kubernetes topology across AWS `us-east-1` and `eu-west-1`. Core components include Route53 latency-based routing, AWS EKS node groups running in isolated private subnets, custom AWS VPC peering configurations, and Karpenter for dynamic pod autoscaling.

Key Achievements

  • Reduced multi-region deploy configuration time from hours to 8 minutes using unified Terraform modules.
  • Designed Karpenter sizing matrices, saving 35% in AWS compute costs compared to managed ASGs.
  • Integrated externalDNS and cert-manager to automatically register DNS records and TLS certs on ingress creation.

Technology Stack

Terraform AWS EKS Karpenter Route 53 VPC Peering ArgoCD
GITOPS / CI-CD

GitOps Continuous Delivery Engine

Architecture Summary

This project implements GitOps continuous delivery workflows. When developers push code, GitHub Actions validates files, executes unit tests, builds security-hardened Docker images, runs Trivy vulnerability scanning, and publishes to a private registry. ArgoCD monitors a separate Git config repository and synchronizes state to the production Kubernetes cluster, maintaining zero-drift environments.

Key Achievements

  • Created a zero-trust build setup: container secrets are loaded dynamically via AWS IAM Roles for Service Accounts (IRSA) rather than static long-lived credentials.
  • Configured webhooks to ensure ArgoCD triggers synchronization within 3 seconds of a configuration manifest commit.
  • Developed automated rollback controls that revert deployments automatically if container health probes fail on startup.

Technology Stack

ArgoCD GitHub Actions Docker Trivy Sealed Secrets Kubernetes
SRE / OBSERVE

Prometheus Service Level Monitoring

Architecture Summary

Designed a comprehensive enterprise observability platform using Prometheus Operator and Grafana deployed inside Kubernetes. The stack collects infrastructure metrics (via node-exporter and kube-state-metrics) along with application custom metrics. The rules engine calculates Service Level Indicators (SLIs) and alerts operators via Alertmanager when metrics breach Service Level Objectives (SLOs).

Key Achievements

  • Drafted PrometheusRules that dynamically detect memory leaks and network anomalies before they impact end-users.
  • Designed unified dashboards presenting core SRE Golden Signals (Latency, Traffic, Errors, Saturation).
  • Structured alerting routes to minimize alert fatigue, reducing false alerts by 60% using Prometheus grouping filters.

Technology Stack

Prometheus Grafana Alertmanager Kubernetes PromQL PagerDuty
K8S / SECURITY

Kubernetes Cluster Security Hardening

Architecture Summary

Designed and configured end-to-end security profiles for a production-grade Kubernetes cluster. Applied security layers include: strict network namespace isolation policies, Admission Controllers (Kyverno) to reject containers seeking root privileges or running with insecure capabilities, and Falco runtime agent daemons monitoring eBPF calls to detect shell escapes or unauthorized filesystem access in real-time.

Key Achievements

  • Enforced CIS Kubernetes Benchmarks across control planes and nodes, increasing compliance ratings to 96%.
  • Constructed Kyverno rules to automatically inject read-only root filesystems and drop default capabilities on application pods.
  • Wrote Falco rules that notify security channels on Slack immediately if a shell process spawns inside a database pod.

Technology Stack

Kubernetes Kyverno Falco (eBPF) NetworkPolicies Kube-bench Secrets Hardening
